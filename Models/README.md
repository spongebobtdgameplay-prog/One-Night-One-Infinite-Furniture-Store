# One Night, One Infinite Furniture Store — Curated Model Starter Pack

This pack contains 19 real source models selected from the Quaternius Ultimate Home Interior Pack.

## What is included
Each model has:
- a ready-to-load `.glb` for Three.js/Babylon
- the original `.obj`
- its matching `.mtl`

Folders are organized by use:
- LivingRoom
- Bedroom
- Kitchen
- Bathroom
- Storage
- Lighting
- Architecture
- Decor

## Important
These models are the geometry/base-prop layer, not the final visual treatment.
For the final horror-store look, use the PBR material kit to retexture the important assets
with realistic fabric, wood, metal, dirt, scratches, and grime.
